# QSol Analytics Website Update Prompt: Hero Copy and CTA Revision

## Objective

Update the QSol Analytics homepage hero section to make the message more concise, relatable, and conversion-focused.

The current hero is strong visually, but the copy should be sharpened around a clearer customer action: helping visitors identify their first useful data solution.

---

## Hero Copy to Implement

Use the following copy structure:

```text
Big-company data tools for small-business teams

The Data Team You Wish You Had.

Fix slow reports.
Tame messy spreadsheets.
Forecast with confidence.
Make AI useful.

[Find Your First Useful Data Solution]
```

---

## Required Changes

### 1. Keep the eyebrow text

Use:

```text
Big-company data tools for small-business teams
```

This should remain above the main headline in green uppercase or the current eyebrow style.

---

### 2. Keep the main headline

Use:

```text
The Data Team You Wish You Had.
```

Maintain the current strong hero typography.

---

### 3. Replace the existing subheadline and bullet list

Remove the current longer subheadline:

```text
Get clearer reports, smarter forecasts, and practical AI tools without hiring an in-house data science team.
```

Remove the current three bullet points:

```text
Turn messy spreadsheets into reliable dashboards and reports
Forecast demand, workload, or risk before problems become expensive
Build practical AI assistants and decision tools around your real workflows
```

Replace them with four short outcome-led lines:

```text
Fix slow reports.
Tame messy spreadsheets.
Forecast with confidence.
Make AI useful.
```

These can be displayed as:
- a short stacked list,
- a subtle animated rotating line,
- or a compact set of clean hero statements.

Preferred implementation:
Use a tasteful rotating/fading text animation that cycles through the four lines, while keeping the main headline static.

Do not animate the main headline.

---

### 4. Update the CTA button

Replace:

```text
Find Your First Data Project
```

With:

```text
Find Your First Useful Data Solution
```

The CTA should scroll the user to the diagnostic section below the hero.

---

## Animation Guidance

If adding animation, keep it subtle and professional.

Recommended animation:
- Fade or slide between the four short lines.
- Duration: approximately 2.5 to 3.5 seconds per line.
- Avoid typewriter animation for the main headline.
- Respect reduced-motion accessibility settings.
- Do not make the hero feel like a generic SaaS template.

Suggested animated line sequence:

```text
Fix slow reports.
Tame messy spreadsheets.
Forecast with confidence.
Make AI useful.
```

If animation is not currently available, display the four lines statically as a short stacked list.

---

## Design Guidance

The hero should remain:
- warm,
- practical,
- SME-focused,
- human,
- clear,
- low-distraction.

Avoid:
- extra technical jargon above the fold,
- extra buttons,
- multiple competing CTAs,
- over-animated text,
- AI clichés such as robots, holograms, glowing brains, or floating neural networks.

---

## Rationale

The updated copy is more concise and customer-facing.

The phrase:

```text
Find Your First Useful Data Solution
```

is preferable to:

```text
Find Your First Data Project
```

because customers are usually looking for a solved problem, not an internal implementation project.

The four short lines map directly onto common SME pain points:

| Line | Customer pain |
|---|---|
| Fix slow reports. | Manual recurring reporting |
| Tame messy spreadsheets. | Fragile spreadsheet workflows |
| Forecast with confidence. | Demand, workload, sales, or risk uncertainty |
| Make AI useful. | AI curiosity without a practical starting point |

The goal is to make the visitor think:

```text
That sounds like us.
```

and then click:

```text
Find Your First Useful Data Solution
```

---

## Acceptance Criteria

The update is complete when:

- The hero eyebrow reads: `Big-company data tools for small-business teams`
- The main headline reads: `The Data Team You Wish You Had.`
- The long subheadline is removed or significantly reduced.
- The old three bullet points are removed.
- The four short outcome lines are added.
- The CTA button reads: `Find Your First Useful Data Solution`
- The CTA scrolls to the diagnostic section.
- The hero remains visually clean and readable over the background image.
- Animation, if used, is subtle and respects reduced-motion accessibility.
